# ADR-0002：MVP 不引入 Agent

## 状态

已接受。

## 背景

项目需要验证的是文档上传、向量检索和带引用的问答，而不是复杂任务规划、工具调用或多步自治执行。

## 决策

MVP 不引入：

- LangGraph。
- ReAct Agent。
- 工具调用。
- 多 Agent 协作。
- 自主循环执行。

使用固定 RAG 链路：

```text
检索
-> 构造 Prompt
-> LLM 生成
-> 保存来源
-> 流式返回
```

## 原因

- 固定 RAG 链路更容易测试和定位问题。
- 减少模型调用次数和不可控行为。
- 降低 Prompt Injection 和工具误用风险。
- 当前需求不需要多步规划。

## 影响

- 不支持复杂任务分解和工具执行。
- 如果未来引入 Agent，必须先更新需求、API、数据库和安全设计。
- 引入 Agent 不能改变现有回答必须带来源的基本要求。
